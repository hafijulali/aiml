# AI/ML Course Notes

This repository contains transcript-grounded notes for AI and machine-learning courses.

## Shareable PDF layout

Each course is self-contained so you can share only its PDFs:

```text
<course>/
  notes/<course>.pdf                 # complete course notes
  notes/shorts.pdf                   # Sessions 1-8 rapid-review cards
  exams/midsem1/exam-guide.pdf       # printable Midsem 1 guide
  exams/midsem1/mock-01.pdf          # answer-free timed mock
  exams/midsem1/mock-01-solutions.pdf
```

Available course directories are `mfml`, `ism`, `dnn`, and `ml`. The answer
key/solutions PDF should be opened only after submitting the answer-free mock.

## Interactive Learning

Load `LEARN.md` in an AI agent or supported IDE—such as Codex or OpenCode—to start an interactive, course-scoped learning experience. The agent will ask which course you want to study, use its available learning material, guide explanations and problem-solving, and provide evidence-backed references.
